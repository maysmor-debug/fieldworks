A few common questions

How does it know I'm driving?

TrackMile uses your phone's motion sensors and GPS together to recognise driving-like movement, then confirms it with clear GPS evidence before logging a trip — so a walk to the shops doesn't get counted as a drive.

Does it drain my battery?

Trip detection is designed to run efficiently in the background using the phone's standard activity recognition, rather than keeping GPS on constantly. Testing feedback on real-world battery use is exactly what the closed testing round is for.

What if it misses a trip?

You can add any journey manually in a few seconds, and this is one of the areas we're actively refining ahead of a public release.

Is it only for car mileage?

No — car, van, motorcycle and bicycle are all supported, each with the correct HMRC rate applied automatically.
